Start

Instalacja

  1. Pobierz `plugin.video.xvaultalpha-2026.07.23.6.zip` ze strony pobierania.
  2. W Kodi otwórz Dodatki > Zainstaluj z pliku ZIP.
  3. Wybierz pobrany ZIP i poczekaj na komunikat o instalacji.
  4. Uruchom xVAULT Alpha z sekcji dodatków wideo.

Do aktualizacji można użyć także repository.xvault.zip z adresu Alpha GitHub Pages. Repozytorium i metadane wskazują na https://mojomedia1812.github.io/xvaultalpha/.

Odtwarzanie

Źródła, jakość i tryby startu

xVAULT zbiera źródła z aktywnych stron indeksujących, rozwiązuje hostery i przekazuje do Kodi tylko odtwarzalne adresy. Przy wyborze ręcznym w menu kontekstowym dostępne są pobieranie, MediaInfo i wysłanie linku do menedżera pobierania.

TrybDziałanie
DialogPokazuje listę źródeł w oknie wyboru.
KatalogPokazuje źródła jako katalog Kodi.
AutoodtwarzaniePróbuje kolejne źródła automatycznie, z limitem czasu dla resolvera i startu playera.

Język streamu

Filtr języka może preferować albo wymuszać pasujące źródła. Przy wartości Wszystkie autoodtwarzanie wymaga przełączenia na Dialog albo Katalog, aby użytkownik świadomie wybrał źródło.

Telewizja

LiveTV

LiveTV w xVAULTalpha używa wyłącznie polskiej listy kanałów. Kanały niemieckie, austriackie, szwajcarskie i jasno obcojęzyczne są filtrowane z katalogu, cache oraz ulubionych.

Katalog

Kategorie polskie: publiczne, prywatne, informacyjne, sport, filmy i seriale, dokumentalne, dzieci, muzyka i regionalne.

Fallback hostów

Jeśli `huhu.to` nie odpowiada, LiveTV próbuje `oha.to`, a potem `vavoo.to`.

EPG i logo

Program i logo są dopasowywane do polskich kanałów, a brakujące dane mają bezpieczne fallbacki.

Sprawdzanie listy

Preflight może sprawdzić dostępność kanałów i ukryć niedostępne do następnego głównego startu xVAULT.

LiveTV lite używa tej samej polskiej listy xVAULTalpha, ale pokazuje uproszczony dostęp do kanałów bez dodatkowej warstwy EPG i ulubionych.

Konta

Synchronizacja i Trakt

xVAULT Sync

Synchronizacja może zapisywać ulubione i stany odtwarzania na serwerze. Hasło nie jest przechowywane w postaci zwykłego tekstu. Po zalogowaniu można wykonać synchronizację ręcznie albo przywrócić kopię ulubionych z serwera.

Trakt

Trakt używa OAuth z kodem urządzenia. Po połączeniu dostępne są watchlista, kolekcja, import i eksport obejrzanych, scrobbling oraz oceny w menu kontekstowym.

Pakiet wsparcia

Narzędzia wsparcia tworzą redigowany pakiet diagnostyczny. Pakiet zawiera wersje dodatku, Kodi i Pythona, ustawienia po redakcji, istotne zależności, wybrane linie logu xVAULT oraz listy plików bez zawartości prywatnych baz danych.

Dane

Prywatność

Do repozytorium nie należy wpisywać prywatnych kluczy, tokenów, haseł, pełnych URL streamów ani danych osobowych. Przy zgłoszeniach błędów wystarczy wersja xVAULTalpha, wersja Kodi, platforma, kroki odtworzenia i zredagowany log lub ID pakietu wsparcia.

Opcjonalne statystyki użycia zbierają tylko techniczne zdarzenia cyklu życia dodatku. Nie są wysyłane tytuły, zapytania wyszukiwania, ulubione, adresy streamów, dane logowania ani prywatne ścieżki.
